# Happy Birthday Nikhitha 🎀 (Chellama's Birthday Scrapbook)

A cute, funny, personal digital scrapbook website built for Nikhitha.

---

## 📸 How to Add Your Photos & Chat Screenshots

The website is set up to automatically detect your photos! Simply drop your files into `assets/images/`:

### 1. Chat Screenshots (Timeline Chapter 01)
Save your screenshots as:
* `assets/images/chat1.jpg` (or `.png`)
* `assets/images/chat2.jpg` (or `.png`)
* `assets/images/chat3.jpg` (or `.png`)

### 2. Photos Together (Polaroid Frames)
Save your photos as:
* `assets/images/photo1.jpg` (or `.png`)
* `assets/images/photo2.jpg` (or `.png`)

> **Note:** Until you add your photos, lovely aesthetic placeholder frames with notes are shown by default so the layout is always beautiful.

## 🚀 How to Deploy on GitHub Pages (Free & Instant)

1. Create a new GitHub repository (e.g., `birthday-nikhitha`).
2. Push all the files in this folder to your repository:
   ```bash
   git init
   git add .
   git commit -m "Happy Birthday Nikhitha 🎀"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   git push -u origin main
   ```
3. In your GitHub repository:
   * Click **Settings** (top navigation).
   * In the left sidebar, click **Pages**.
   * Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
   * Click **Save**.
4. GitHub Pages will give you your live link within 1–2 minutes (e.g. `https://<username>.github.io/<repo-name>/`)! Send it to Nikhitha on WhatsApp or Instagram!
